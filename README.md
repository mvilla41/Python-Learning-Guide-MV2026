It seems like Python is very relevant for coding in the modern day, but there are not many resources 
available if you are a student who wants to pick up the language at the level of a sophomore CS student. 
People in this position have a strong grasp of the fundamental knowledge necessary to understand the 
basics (and therefore, do not need to learn at the level of a beginner), but may not benefit from the 
excessive jargon and features most technical  resources explain. With that being said, I have decided 
to create this learning guide to gloss over the elementary concepts in Python that should already be 
familiar to competent sophomore CS students, but explain notable differences in syntax and keep advanced 
topics palatable to our current level of knowledge in C++. Hopefully by the end, you will be able to 
write in Python at a similar level as a sophomore or junior who learned C++ in class.
